# MW-STORAGE Brand Assets

This directory contains the initial project identity artwork.

| Asset | Purpose | Dimensions |
|---|---|---:|
| [mw-storage-logo.svg](mw-storage-logo.svg) | Primary horizontal logo | 900 × 220 |
| [mw-storage-hero.svg](mw-storage-hero.svg) | README hero banner | 1600 × 520 |
| [mw-storage-social-preview.svg](mw-storage-social-preview.svg) | Social preview source artwork | 1280 × 640 |

## Visual system

- Midnight blue / graphite foundation
- Warm gold accent
- Silver-white wordmark
- Horizon, network, and data-vault motifs
- Tagline: **Preserve What Matters. Keep Data Within Reach.**

## Usage

Use the hero at the top of the repository README. Keep the logo's aspect ratio and clear space. Do not present visual motifs as evidence of security certification, compliance, or guaranteed durability.

The social preview is supplied as SVG source. GitHub's repository social-preview setting requires an accepted raster upload; export this SVG to PNG or JPG and upload it in repository Settings → Social preview. This repository commit does not change that setting.
